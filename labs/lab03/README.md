## Структура

labs/lab03/
- `main.py` — створення FastAPI-застосунку та службові маршрути.
- `config.py` — налаштування й обмеження предметної області.
- `schemas.py` — Pydantic-моделі запитів і відповідей.
- `database.py` — підключення та ініціалізація SQLite.
- `repository.py` — SQL-операції з базою даних.
- `routers/categories.py` — маршрути категорій.
- `routers/records.py` — маршрути записів.
- `schema.sql` — структура таблиць та обмеження.
- `seed.json`, `seed.py` — початкові дані та їх одноразове завантаження.

## Запуск

Команди потрібно виконувати з кореневої папки проєкту, де розташовані каталоги `labs` і `shared`.

```powershell
python -m labs.lab03.seed
uvicorn labs.lab03.main:app --reload --host 127.0.0.1 --port 8000
```

Після запуску документація Swagger UI доступна за адресою:

`http://127.0.0.1:8000/docs`

OpenAPI-схема:

`http://127.0.0.1:8000/openapi.json`

## Основні маршрути

| Метод | Маршрут | Призначення |
|---|---|---|
| GET | `/ping` | Перевірка доступності API |
| GET | `/student` | Дані студента та номер варіанта |
| GET, POST | `/categories` | Список і створення категорій |
| DELETE | `/categories/{category_id}` | Видалення порожньої категорії |
| GET | `/records` | Список записів із фільтрами та пагінацією |
| GET | `/records/{record_id}` | Отримання запису за ID |
| POST | `/records` | Створення запису |
| PUT | `/records/{record_id}` | Повна заміна запису |
| DELETE | `/records/{record_id}` | Видалення запису |
| POST | `/records/bulk` | Атомарне масове додавання 1–100 записів |

## Фільтри GET `/records`

- `category_id` — додатний ID категорії;
- `status` — `new`, `in_progress` або `done`;
- `min_value` — мінімальне значення ризику від 0 до 10;
- `q` — буквальний регістрозалежний пошук у назві;
- `limit` — кількість результатів від 1 до 100, типове значення 20;
- `offset` — кількість пропущених записів, типове значення 0.

Усі передані фільтри поєднуються через AND. Результати сортуються за ID за зростанням.
